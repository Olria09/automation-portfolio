# Tic-Tac-Toe CLI

A small terminal game based on my original Python Tic-Tac-Toe exercise. Play as **O** against the computer (**X**), which opens in the center and uses the minimax algorithm to choose its moves.

## Requirements

- Python 3.10 or newer
- No third-party packages

## Run

```bash
python ttt.py
```

Enter a square number from 1 to 9. The board shows the available numbers; occupied squares show X or O. Invalid and occupied choices are rejected without ending the game.

The computer plays optimally. A perfect game can end in a draw, and the computer cannot be beaten.
